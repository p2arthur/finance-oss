# Contributing to finance-oss

Thank you for your interest in contributing to finance-oss! Your help is valuable to improve this project.

## How to Contribute

- **Discuss ideas and report issues:** Use the GitHub Issues feature to suggest new ideas, report bugs, or request features.
- **Propose changes:** Fork the repository, make your changes, and submit a pull request for review.

## Guidelines

- Please keep contributions focused on improving documentation and project planning at this stage.
- There is currently no automated build or test suite, so please ensure your documentation changes are clear and well-formatted.

## Communication

For questions or discussions, please open an issue or comment on existing ones.

We appreciate your contributions to help build a useful toolkit for financial agents!
